## `record_inspection` authorization rule

The plan's live-schema adaptation is accepted for H1--C4: before each Product mutation, the coordinator records an inspection for the **reviewed intended action** and dispatches only after that inspection returns authorization. The intended action must match the row above exactly: method, locator, current Actor, resource where applicable, and JSON body. A generic inspection, a prior authorization, or an authorization for a neighbouring action is insufficient.

For H4 recovery and L2a/L2b, inspection must follow an amended, reviewer-approved concrete row; it cannot convert an unreviewed advertised action into dispatch authority. `record_inspection` is authorization bookkeeping, not final Knowledge fact recording. Surfaces, Journeys, Observations, and Evidence will be reviewed from the completed captures in the later evidence pass before Perquiro writes occur.

No Product request was made and no Perquiro record was written during this review.
