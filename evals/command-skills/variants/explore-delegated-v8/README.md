# Review the plan before Product changes

This variant keeps v7's checklist and recording rules but gives the existing reviewer two passes: first the outcome plan and request order, then the evidence and proposed Knowledge. The coordinator resolves plan omissions and state dependencies before the first Product mutation. The reserved request allowance remains reserved until evidence review. The reviewer receives the human request and installed skill as its criteria, and verifies cells marked complete as well as pending cells. A request that reaches the wrong starting state does not complete the intended branch.

Earlier walks consumed state needed for omitted checks: a loan was returned before its repeat check, and the v7 library walk made both unavailable books available before trying the unavailable-reservation branch. A review after the walk cannot restore those states. This change reviews dependencies while they can still be preserved. It does not add a worker role, permit reviewer writes, supply fixture answers or enlarge the request budget.

The v7 checklist also marked its unavailable-reservation check complete after it instead created a reservation. Its recovery row was weaker than the skill's required follow-through. Review approved those rows. The v8 reviewer therefore checks actual outcomes and the source rules, rather than accepting checklist labels as proof.

Use fresh candidates and the same frozen inventories. The pre-mutation plan review is a workflow change; retain both review passes and their actual order relative to Product events.
