## Procedure

Copy and hash the supplied package without changing it. Run its nine contract checks and all eight dry runs. Probe impact handling, malformed responses, host precedence, and exported request consistency. Authored responses establish software behavior only.

Run TypeSafe on all eight situations in original order, then with shuffle seeds 7 and 29. Each suite has six API calls and two deterministic host bypasses. Retain all failures. No retries beyond these prespecified order repetitions. Record complete raw successful responses, distributions, IDs, input hashes, latency and reported token usage. Never persist the API key. Do not treat unavailable responses as wrong rankings or silently exclude them.

Two independent ordinary planning agents receive the eight situations through neutral paths and an identical organic request. Remove case names, expected answers, ranking code and evaluation instructions. Rename the candidates field to available_checks. Preserve evidence and controls. They choose a next check or explain why none is useful. These are static planning baselines, not Product executions or full Explore runs. Different available models provide a limited check of fixture difficulty; the eventual treatment comparison must hold the Explore model constant.

A separate reviewer receives anonymized outputs together in one pass and the criteria below. Only GPT models are available here, so cross-family judging is unavailable. The parent reads all outputs and reconciles the review with the evidence. Tool-level local transcripts may be unavailable; report this rather than claiming transcript-verified isolation. No private chat history is read.
